# LearnFlow — 让你把握主线的高效学习流

LearnFlow 是一个 AI 驱动的个人学习规划与复习工作流系统。帮助学习者在进入新领域或遇到学习瓶颈时获得清晰的思路和方向，在信息嘈杂的时代保持专注的学习主线。

---

## 🎯 平台宗旨

> 希望能在你进入某个领域或学习到某个瓶颈阶段时提供一些思路和方向。也希望能在这个信息嘈杂的时代让你有一条专注的主线。

---

## 🌟 核心特性

### 1. 学习规划 — 知识树与自动排期

- **领域创建**：选择想学习的领域，填入主题、目的、范围、行业等条件进行创建
- **AI 知识树生成**：进入卡片后可一键生成学习路线树，AI 自动拆解为可执行的知识节点
- **节点管理**：生成目录树后可自由增删改节点，支持多层级嵌套
- **自动排期**：基于 DFS 算法结合每日时间和周末策略自动分配学习日期
- **自动拆分**：智能识别超大节点并按每日学时限制自动拆分

### 2. Markdown 笔记 — AI 强化学习

- **双栏编辑**：每个节点对应一个 Markdown 笔记，支持编辑与实时预览
- **AI 笔记整理**：提供逻辑纠错与结构重排，双栏对比视图，一键采纳
- **AI 知识衍生**：根据笔记内容提取衍生知识点与强化思路，支持快捷插入
- **子节点目录**：父级节点自动预览直接子节点的标题和学习状态

### 3. 每日看板 — 学习进度可视化

- **今日任务**：集中展示今日计划、待复习节点、逾期未完成任务
- **学习统计**：今日完成数、学习时长、活跃领域数等关键指标
- **每周 AI 总结**：一键读取本周学习笔记，生成高阶学习和复习建议
- **状态同步**：与 Zustand Store 及本地 IndexedDB 实时自愈性同步

### 4. 复习规划 — 间隔重复记忆

- **复习模板**：内置艾宾浩斯遗忘曲线模板，支持自定义复习节奏
- **多视图切换**：今日待复习、全部计划列表、月度复习日历三大视图
- **进度追踪**：完成进度环、逾期标签、颜色编码直观显示复习状态
- **灵活安排**：可对知识点安排复习计划，支持多套模板并行使用

### 5. RSS 订阅 — 领域资讯聚合

- **订阅管理**：自由添加技术博客、文献等 RSS 源
- **资讯检索**：在阅读器中便捷检索与当前知识点相关的资讯
- **推荐订阅源**：
  - [GetPodcast](https://getpodcast.xyz/) — 各类播客的 RSS 订阅源
  - [RSSHub](https://rsshub.netlify.app/) — 各类 RSS 订阅源
  - [Awesome RSSHub Routes](https://jackyst0.github.io/awesome-rsshub-routes/) — 新闻/咨询/学术/技术类 RSS 订阅源

### 6. Notion 同步 — 知识库整合

- **一键同步**：将本地知识树与笔记同步至 Notion 知识库
- **多层级转换**：支持 Blocks 嵌套转换（标题、代码块、列表等格式）
- **增量更新**：页级增量追加，避免重复同步
- **配置灵活**：在 Notion Developer 平台申请 Access Token，配置后即可使用

## 🛠️ 技术栈

- **前端框架**：Next.js 16 (App Router) + React 19 + TypeScript
- **状态管理**：Zustand（内存缓存 + IndexedDB 双层架构）
- **样式方案**：Tailwind CSS v4（Sage Flow 温暖奶油色系视觉）
- **动效库**：Framer Motion
- **本地存储**：IndexedDB（基于 `idb` 库）
- **AI 集成**：OpenAI / Anthropic 双协议支持，后端 API 路由代理
- **图标系统**：Lucide React
- **构建运行**：Bun

## 🚀 快速开始

### 1. 安装依赖

推荐使用 [Bun](https://bun.sh) 进行包管理：

```bash
bun install
```

> **注意**：如果 `sharp` 编译卡住，请使用：
> ```bash
> SHARP_IGNORE_GLOBAL_LIBVIPS=1 bun install
> ```

### 2. 启动开发服务器

```bash
bun dev
```

启动后访问 [http://localhost:3000](http://localhost:3000) 即可使用。

## 🔒 隐私与配置

所有 AI 能力与 Notion 同步需要您在 **Token 配置** 页面配置相应的 API 密钥。敏感密钥均持久化存放在您本地的浏览器 IndexedDB 中，调用 AI 时仅通过 Next.js 本地中转 API 进行 Header 注入，绝不会上传至第三方服务器。

### 📌 关于 `token-load-env` 分支

如果您使用的是 `token-load-env` 分支，LLM 相关配置可通过系统环境变量进行设置：

- **配置方式**：在项目根目录创建 `.env` 文件，添加以下环境变量：
  ```bash
  # AI 配置（必填）
  AI_API_KEY=your_api_key_here
  AI_PROVIDER=openai          # 提供商，如 openai / anthropic / deepseek 等
  AI_MODEL=gpt-4o             # 模型名称
  AI_BASE_URL=https://...     # API 请求地址
  ```
- **优先级**：系统环境变量 > 前端 Token 配置页面
- **优势**：适合服务器部署或多环境配置，避免每次在浏览器中重复配置
- **注意**：Notion Token 不支持环境变量配置，仍需在前端 Token 配置页面中设置

## ⚠️ 平台局限性

1. **数据存储**：目前采用浏览器 IndexedDB 存储知识点树、笔记内容和各项配置，更换浏览器或清空缓存后会丢失。后期考虑迭代为 SQLite 或本地文件存储。

2. **运行形态**：目前暂时以 Web 端方式运行，后续待功能完善需要迭代为客户端方式，或客户端内嵌入浏览器。

3. **AI 能力**：因为目前统一采用一个 LLM 提供所有功能，提供的知识信息可能不够准确。预想解决方案：
   - 引入多个行业领域微调过的大模型
   - 引入领域专家提供的知识库
   - 优化笔记整理和扩展的技术方案
